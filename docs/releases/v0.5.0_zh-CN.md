# Daat Locus 0.5.0

## 重点更新

- 新增 Study 学习模式：一个独立的知识图谱 agent，拥有自己持久化的 SQLite 图谱、工具集、会话作用域和 WebUI 网络视图。
- 以本地「清空并归档」策略取代模型生成的上下文压缩：被压缩的历史写入 dashboard 数据库归档，并通过新的 `read_history` 工具按需恢复。
- 新增 `/ask` 讨论轮，在禁用工具的情况下回答问题。
- 新增按轮次粒度的 `config.toml`、skills 与 workflow 目录热重载，并打通 `/sleep auto` 开关。
- 在模型生成过程中向客户端流式输出实时 assistant 与 thinking 草稿。
- 移除第三方工作区 App 子系统，并精简内置 skill 目录。

## Study 学习模式

- 新增 `study` 会话作用域与 App，底层为 SQLite 知识图谱（模块、节点、带类型的关系、按节点的理解度百分比、题库），存储在 `~/.daat-locus/study/` 下。
- 新增生成的 `study__*` 工具，包括 `study__create_module`、`study__read_node`、`study__search_nodes`、`study__find_similar`、`study__link_nodes`、`study__unlink_nodes`、`study__merge_nodes`、`study__update_progress`、`study__add_questions`、`study__record_attempt` 和 `study__maintenance_report`。
- 将 study 会话的工具面收窄为 study 工具加上 `finish_and_send`、`update_plan` 和 `read_history`。
- 在 WebUI 中新增 Study 标签页，包含可交互的知识网络视图与聊天，并提供带测试的布局模块。
- 向 dashboard 流发布单调递增的图谱 revision，使 Study 标签页在 agent 工作过程中实时刷新（带防抖），并保留轮次结束时的刷新作为回退。
- 在节点创建、更新或合并时发布结构化 focus 提示，使客户端定位并打开受影响的节点；搜索等只读操作不会改变客户端视图。
- 新增 Obsidian vault 导入（frontmatter 别名/标签、wikilink 关系、可预览的 dry run、幂等重复导入），以及导出为 Obsidian vault 归档或带可选题库的 JSON 备份。
- 新增 `prompts/apps/study.md`，并记录 Study 模式的设计与边界。

## 会话与运行时

- 以本地「清空并归档」策略取代模型生成的上下文压缩：被压缩的历史写入 dashboard SQLite 归档，运行时重置为 recovery 提示，由模型通过新的 `read_history` 工具恢复任务状态。删除了历史压缩相关的 prompt 以及主模型压缩调用路径。
- 允许在 `/ask` 轮内使用 `read_history`。
- 流式输出实时 assistant 与 thinking 草稿，并在 thinking 块折叠时预览其尾部内容。
- 新增禁用工具链的 `/ask` 讨论轮，并修正 daemon 中 `/ask` 在 dashboard 命令之前的路由顺序。
- 在恢复与中断之间保留上下文，并按会话隔离 token 估算校准。
- 批量工具结果返回后仍保留工具生成的图像。

## 配置与热重载

- 新增 `config_hot_reload`（按轮次粒度的 `config.toml` 重载）与 `catalog_hot_reload`（每轮重载 skills 与 workflow 目录）；daemon 会热重载其 Telegram transport。
- 端到端打通 `/sleep auto` 自改进开关：持久化 `config.sleep.enabled`，在空闲/强制后台 sleep 时受控，同时保留手动 `/sleep run`。
- 为 chat、settings、sidebar 和共享 UI 文案新增 WebUI 国际化（react-i18next），并在设置和状态页面新增 sleep 自动运行开关。
- 日志改为输出 RFC3339 本地时间戳。

## 工作流

- 新增内置只读 `investigate` 工作流。
- 将 worker 输入渲染为可读内容、输出 worker thinking，并在运行检查器中暴露 worker 的 `edit_file` 活动。
- 为工作流 worker 保留 opencode 会话亲和性。

## Daemon、WebUI 与本地文件

- 使用 CodeMirror 高亮会话日志，并支持从 WebUI 打开本地文件，同时为会话日志来源添加标题。
- 在重生会话前终止孤儿会话进程。
- 在图像之外支持通用文件附件（最大 32 MiB）；文件会被暂存到 `<workspace>/attachments/`，并在 claimed input 中以可读路径引用。
- 将 Study 图谱操作移入聊天 composer 菜单，并以待发送 chips 形式渲染附件。
- 向上滚动时更早释放 sticky-bottom 滚动锁定。

## 提供商与模型目录

- 加固 OpenAI 兼容的 chat 请求，并向 opencode gateway 发送 opencode session 头。
- 记录 models.dev 目录刷新流程，并新增构建期快照。
- 按当前 models.dev 目录更新 reasoning 选项处理与模型容量测试。

## Scope Engine 与文件锚点

- 安全迁移失效的代码锚点，并为 `read_file` 和 `edit_file` 迁移已观察到的锚点。
- 将未知的 `search_code` type 视为字面文件后缀，使搜索对非代码文件仍然可用。

## 移除项

- 移除第三方工作区 App 子系统（工作区 App 沙箱、持久化与同步，以及相关的 CLI、daemon 和 bootstrap 接线）。
- 将内置 skill 目录精简到 `author-workflow`，并移除内置 skills 目录裁剪逻辑。
