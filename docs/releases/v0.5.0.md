# Daat Locus 0.5.0

## Highlights

- Added Study mode: a dedicated knowledge-graph agent with its own persistent SQLite graph, tool set, session scope, and WebUI network view.
- Replaced model-generated context compaction with local clear-and-archive compaction; archived history lives in the dashboard database and is restored on demand through the new `read_history` tool.
- Added `/ask` discussion turns that answer questions with tools disabled.
- Added turn-granular hot reload for `config.toml`, skills, and workflow catalogs, plus end-to-end `/sleep auto` control.
- Streamed live assistant and thinking drafts to the clients as the model generates them.
- Removed the third-party workspace app subsystem and trimmed the built-in skill catalog.

## Study Mode

- Added a `study` session scope and app backed by a SQLite knowledge graph (modules, nodes, typed relations, per-node understanding percentages, and a question bank) stored under `~/.daat-locus/study/`.
- Added generated `study__*` tools, including `study__create_module`, `study__read_node`, `study__search_nodes`, `study__find_similar`, `study__link_nodes`, `study__unlink_nodes`, `study__merge_nodes`, `study__update_progress`, `study__add_questions`, `study__record_attempt`, and `study__maintenance_report`.
- Narrowed the study session tool surface to the study tools plus `finish_and_send`, `update_plan`, and `read_history`.
- Added a WebUI Study tab with an interactive knowledge-network view and chat, including a dedicated layout module with tests.
- Published a monotonic graph revision to the dashboard stream so the Study tab refreshes live while the agent works (debounced), with a turn-end refresh fallback.
- Published structured focus hints when nodes are created, updated, or merged so the client moves to and opens the affected node; read-only operations such as search leave the client view untouched.
- Added Obsidian vault import (frontmatter aliases/tags, wikilink relations, previewable dry run, idempotent re-import) and graph export to an Obsidian vault archive or a JSON backup with optional question bank.
- Added `prompts/apps/study.md` and documented the study mode design and boundaries.

## Session And Runtime

- Replaced model-generated context compaction with a local clear-and-archive strategy: compacted history is written to the dashboard SQLite archive, the runtime resets to a recovery prompt, and the model restores task state with the new `read_history` tool. Removed the history-compaction prompts and the main-model compaction call path.
- Allowed `read_history` during `/ask` turns.
- Streamed live assistant and thinking drafts, and previewed the thinking tail when the block is collapsed.
- Added `/ask` discussion turns with tools disabled, and routed `/ask` before dashboard commands in the daemon.
- Preserved context across recovery and interrupts, and isolated token-estimate calibration per session.
- Kept tool images available after batched tool results.

## Configuration And Hot Reload

- Added `config_hot_reload` for turn-granular `config.toml` reload and `catalog_hot_reload` for per-turn skills and workflow catalog reload; the daemon hot-reloads its Telegram transport.
- Wired the `/sleep auto` self-improvement toggle end to end: it persists `config.sleep.enabled` and gates idle/forced background sleep while manual `/sleep run` stays available.
- Added WebUI i18n (react-i18next) for chat, settings, sidebar, and shared UI strings, with a sleep auto-run toggle in settings and status pages.
- Emitted RFC3339 local-time timestamps in logs.

## Workflows

- Added a built-in read-only `investigate` workflow.
- Rendered worker input readably, emitted worker thinking, and surfaced worker `edit_file` activity in run inspectors.
- Preserved opencode session affinity for workflow workers.

## Daemon, WebUI, And Local Files

- Highlighted session logs with CodeMirror and allowed opening local files from the WebUI, with titled session log sources.
- Terminated orphaned session processes before respawn.
- Supported generic file attachments (up to 32 MiB) alongside images; files are staged into `<workspace>/attachments/` and referenced by readable paths in the claimed input.
- Moved study graph actions into the chat composer menu and rendered attachments as pending chips.
- Released the sticky-bottom scroll latch sooner when scrolling up.

## Providers And Model Catalog

- Hardened OpenAI-compatible chat requests and sent opencode session headers to the opencode gateway.
- Documented the models.dev catalog refresh pipeline and added a build-time snapshot.
- Updated reasoning-option handling and model-capacity tests to follow the current models.dev catalog.

## Scope Engine And File Anchors

- Relocated stale code anchors safely, and relocated observed anchors for `read_file` and `edit_file`.
- Treated unknown `search_code` types as literal file suffixes so search keeps working for non-code files.

## Removals

- Removed the third-party workspace app subsystem (workspace app sandbox, persistence, and sync, plus the related CLI, daemon, and bootstrap wiring).
- Trimmed the built-in skill catalog to `author-workflow` and removed the built-in skills directory pruning.
