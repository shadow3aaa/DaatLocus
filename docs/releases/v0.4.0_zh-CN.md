# Daat Locus 0.4.0

## 重点更新

- 新增一等公民级 Lua 工作流，可通过类型化输入输出、普通 Lua 控制流、宿主 App 工具和工作流局部工具编排隔离的 agent worker。
- 在 TUI 和 WebUI 中新增工作流执行检查器，可查看运行图、actor 执行尝试、流转关系、状态、耗时和 worker 活动。
- 新增内置 `goal` 和 `search` 工作流，并支持持久化工作流 actor，使其在连续运行之间保留 worker 局部会话和 App 状态。
- 新增本地 `view_image` 运行时工具，使支持视觉能力的模型可以检查工作区中已有的图像。
- 改进会话展示，新增非阻塞 AI 会话标题、工作耗时标识、Markdown 代码块语法高亮和响应式宽表格。
- 改进 Coding 和提供商可靠性，新增非 SCOPE 文件结构化编辑回退、非阻塞 LSP 响应处理，以及与提供商错误文本无关的请求降级重试。

## Lua 工作流

- 新增 Lua 5.4 工作流运行时，用于执行可产生副作用的编排程序。
- 为主 agent 新增类型化 `workflow__<id>` 工具，并为通过 `/workflows` 进行的交互调用生成输入表单。
- 新增隔离的工作流 worker，各自拥有独立的会话历史、App 实例、运行时状态和 Plan。Worker 可使用主模型或高效模型，并且只会获得获准使用的宿主工具和工作流局部工具。
- 新增 `workflow.agent`、`workflow.await`、`workflow.await_all` 和 `workflow.tool` 原语，支持顺序、并发、条件、递归、验证、修订和重试流程。
- 新增持久化 actor：同一 actor 连续运行时会保留 worker 局部历史和 App 状态，直到工作流显式调用 `actor:reset()`。
- 为 `await`、`verify`、`revision` 和 `retry` 交接新增流转标签。
- 移除固定的 worker 轮次上限；运行会持续到完成、失败、被中断或达到外部运行预算为止。
- 从全局目录 `~/.daat-locus/workflows/*.lua` 加载用户工作流；设置 `DAAT_LOCUS_HOME` 时则从 `$DAAT_LOCUS_HOME/workflows` 加载。
- 新增编译进发布二进制文件的内置 `goal` 和 `search` 工作流。同 id 的用户文件会覆盖内置定义。
- 新增 `examples/workflows/research_brief.lua`、中英文工作流文档，以及内置 `author-lua-workflow` skill。
- 被中断的工作流默认不可重放，因为工作流可能产生文件系统和进程副作用。

## 工作流检查器

- 在会话活动中新增进行中和已完成的工作流运行记录。
- 在 TUI 和 WebUI 中新增工作流检查器，可查看状态、输入输出、错误、await group、actor、worker 执行尝试、执行耗时和流转关系。
- 在 WebUI 中新增图形视图，用于展示 actor 关系以及验证、修订和重试循环。
- 持久化 worker 活动并支持分页加载，无需在每次 Dashboard 快照中嵌入完整事件流即可检查较早的 worker 事件。
- 新增按执行尝试划分的 worker 活动视图，同一持久化 actor 的重复运行仍会保留为不同的执行尝试。
- 修复会话级工作流运行的 Dashboard 路由和检查器更新。

## 会话与运行时

- 在轮次完成和活动变化后使用高效模型生成会话标题，并通过基于签名的去重机制避免重复模型调用。
- 将标题生成移至后台任务，避免阻塞运行时调度器。
- 在 TUI 和 WebUI 的已完成回复中新增工作耗时元数据。
- 改为使用主模型压缩运行时上下文；高效模型仍用于会话标题生成、判定等后台工作。
- 无法获得精确 token 信息时，继续采用保守的上下文预算估算。
- 在重试之间保留运行时故障熔断状态，确保重复失败仍能安全停止。
- 统一内置 App 与工作区 App 的工具执行契约，并隔离工作流 worker，使其不具备主会话的事件完成权限和工作流入口工具。

## TUI 与 WebUI

- 在两个客户端中新增 `/workflows` 选择和类型化输入流程。
- 将 agent 回复渲染为一个完整 Markdown 块，不再把首行拆分为单独标题。
- 在 TUI 中新增 fenced Markdown 代码块语法高亮。
- 让 WebUI 中的宽 Markdown 表格支持响应式布局。
- 新增工作流运行与 worker 活动检查器，支持实时状态和耗时显示。
- 修复活动前缀换行后超出可用宽度时触发的 TUI panic。

## 运行时工具与 Coding

- 新增 `view_image`，可读取经过沙箱检查、本地已有且不超过 10 MiB 的 PNG、JPEG、WebP 和 GIF 文件。该工具仅在所选模型支持图像输入时提供。
- 为支持视觉能力的工作流 worker 提供相同的图像检查能力。
- 对于不属于 SCOPE 解析器管理范围的文件，允许 `coding__edit_code` 回退到普通结构化文件编辑；受支持的源文件仍保留语法解析验证和影响传播审查。
- 为普通非 SCOPE 文件新增结构化编辑支持，agent 无需切换编辑契约。
- 当只需按位置读取时，允许 `coding__read_code` 接受不带哈希的行号；编辑锚点仍会验证哈希。
- 修复 LSP 响应处理，避免服务器通知阻塞响应传递。

## 模型与提供商

- 以确定性的 HTTP 400 降级管线取代提供商错误文本匹配，依次降级 `tool_choice` 和 thinking budget 的表示形式，提升对 opencode-go、Console Go 等 OpenAI 兼容网关的兼容性。
- 修复未匹配到已知 models.dev 提供商条目时的 reasoning 选项选择。
- 构建时下载最新 `models.dev` 目录并将该快照编译进二进制文件，同时保留运行时缓存刷新和保守回退机制。
- 将导入的 Codex OAuth 凭据持久化到 Daat 管理的私有文件中，并在提供商配置中记录所选 `auth_file`。
- 在 WebUI 设置流程中新增 Codex OAuth 文件选择。

## 修复与可靠性

- 守护进程 token 权限错误不再被静默忽略，而是向上返回，避免继续使用不可用的认证状态。
- 配置的沙箱后端不可用时返回明确错误。
- 修复守护进程托盘、持久化、工作流、工作区 App 和沙箱代码中的跨平台 CI 回归。
- 在 Windows、Linux 和 macOS 上正确限制各平台专用的沙箱辅助函数。
- 更新 Markdown 渲染器子模块，并移除未使用的渲染器产物和发布产物。

## 兼容性与迁移说明

- Lua 工作流是 0.4.0 新增的运行时子系统，与 skill 概念不同。Skill 仍是 Markdown 指南；工作流则是可执行的编排程序。
- 工作流通过 `~/.daat-locus/workflows` 在所有会话之间共享。重新加载 skill 时也会重新加载工作流目录。
- 重新加载时，未经修改的旧版安装器 `goal.lua` 和 `search.lua` 副本会被移至 `~/.daat-locus/workflows/legacy-builtin-workflows/`，避免覆盖当前内置版本；修改过的文件仍作为显式用户覆盖保留。已有备份冲突需要手动解决。
- 现有 Codex OAuth 提供商文件会从旧配置目录迁移到 `~/.daat-locus/codex-auth`，并将 `auth_file` 写入 `config.toml`；显式配置的自定义认证路径会保留。
- 工作区 App 的 `config`、`init`、`render_state`、`list_tools`、`call_tool` 和 `poll_notices` hook 兼容性保持不变。
- 源码构建现在需要访问 `https://models.dev/api.json`；`build.rs` 使用未固定版本的实时响应，超时时间为 30 秒。如果目录不可用、为空或无效，构建将失败。
