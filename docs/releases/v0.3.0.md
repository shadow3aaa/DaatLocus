# Daat Locus 0.3.0

## Highlights

- Replaced the primitive system with an OpenSkill-based skill architecture, removing workflows and consolidating reusable instructions into portable `SKILL.md` files.
- Replaced the markdown renderer backend (pulldown-cmark → `daat-locus-md` submodule) for improved rendering fidelity in both TUI and WebUI.
- Added a DeepSWE benchmark adapter (`benchmark/DeepSWE`) for running agent evaluations inside isolated Docker sandboxes.
- Moved `api_style` from provider-level to per-model configuration, giving finer control over API compatibility per model.
- Added Windows daemon launcher packaging and macOS PKG installer support.
- Added a WebUI setup flow for guided first-time config readiness.

## Skill System

- Replaced the legacy `primitive` system with an OpenSkill-compatible skill architecture. Skills are now plain `SKILL.md` files organized by topic rather than structured primitive records.
- Removed the workflow subsystem entirely; workflow instructions migrated to skill files.
- Added skill improvement planner scaffolding for future sleep-time skill refinement.
- Updated all documentation, prompts, and tool descriptions to use skill terminology.

## WebUI

- Added a setup wizard flow for guided first-time configuration.
- Added a copy button on agent reply messages.
- Added a directory browser dialog backed by the daemon directory listing API.
- Added dark mode toggle.
- Moved sidebar navigation to the footer.
- Improved mobile navigation and responsive layout.
- Restyled code block rendering and diff row wrapping inside message cells.
- Added localization coverage for setup pages.
- Rendered agent replies as a single markdown block instead of bolding the first line.
- Preserved blank lines and indentation in rendered message content.
- Reduced initial bundle size with code splitting.
- Fixed sidebar overflow, history autoload scrolling, and daemon auth handling.
- Made settings controls full-width and refined status dashboard layout.

## TUI

- Assistant cells now render the full body as markdown without extracting a separate title line.
- Replaced idle runtime polling with wake events for lower CPU usage.
- Preserved blank lines in streamed terminal output.
- Showed elapsed timing on the latest activity event.
- Added recent task activity display on the dashboard.

## CLI

- Added `daat-locus prompt-reset` subcommand to clear cached prompts.
- Added `daat-locus mem-reset` subcommand to reset memory state.
- Added session listing and target-send support.
- Flattened daemon CLI commands for simpler invocation.
- Added daemon directory listing API for programmatic file browsing.

## Coding and Project Tools

- Normalized Windows `\\?\` extended-length path prefixes so scope-engine comparisons behave correctly on Windows.
- Skipped unreadable files instead of failing the entire project search.
- Included all language extensions in type filters (not just primary extensions).
- Reported tree-sitter parse diagnostics visibly.
- Elided repeated coding source records in context to reduce prompt bloat.
- Relaxed `edit_file` / `coding__edit_code` params to support new file creation without explicit anchors.
- Added `force_no_elide` parameter to `read_file` for precise content inspection.

## Markdown Rendering

- Replaced `pulldown-cmark` with the bundled `daat-locus-md` submodule (forked from `ratatui-markdown`).
- Improved markdown rendering consistency between TUI and WebUI.
- Fixed heading and emphasis rendering in activity cells.

## Model and Provider Setup

- Moved `api_style` from provider-level to per-model configuration; each model entry now controls its own API style.
- Added request-level timeout with exponential backoff and max retries to the model turn retry loop.
- Injected rustdoc comments into JSON schema descriptions via `#[model_schema]` for richer model-facing tool documentation.
- Dropped empty tool-call placeholder builders that could confuse providers.
- Added persona name template resolution in prompts.

## Telegram

- Routed Telegram dashboard commands through the session manager.
- Moved Telegram message delivery to the manager daemon.
- Grouped Telegram dashboard command dependencies for cleaner architecture.

## Desktop and Packaging

- Added Windows daemon launcher package with standard bootstrapper UI.
- Added macOS PKG installer packaging.
- Updated release workflow for multi-platform setup artifacts.
- Fixed Windows launcher install layout.
- Fixed macOS first-run WebUI launch behavior.

## DeepSWE Benchmark

- Added `benchmark/DeepSWE` adapter that runs the Daat Locus agent against DeepSWE evaluation tasks.
- Supports local source-tree packaging with automatic sandbox builds, or pre-built Linux binaries.
- Managed DeepSWE repo cloning with optional `--refresh-deep-swe` pull-before-run.
- Patches installed Pier proxy/docker scripts for compatibility with the adapter's network policy.

## Fixes and Reliability

- Fixed missing-completion follow-up delivery as a user message.
- Preserved indentation in `compact_body_lines` by switching from `trim` to `trim_end`.
- Clarified assistant-text-is-internal-record-keeping semantics in core prompts.
- Hardened provider timeouts and OAuth defaults.
- Reset stale runtime turns on loop entry to prevent hang states.
- Improved session IPC diagnostics and error recovery.
- Fixed `terminal_exec` session-id handling: enforced null-only for new sessions, treated string `"null"` as create-new.
- Blocked interactive terminal authentication flows from the runtime.
- Replaced idle polling with wake events across the dashboard to reduce CPU usage.
- Fixed `Working` status display when a session dies.
- Removed the `EventSource` enum; event origin is now derived from the payload.
- Removed the app notice mechanism; all notices now flow through regular event channels.
- Fixed Windows LSP file URI normalization.
- Fixed Clippy warnings across the codebase.

## Dependencies

- Updated `reqwest` 0.12 → 0.13.
- Updated `tree-sitter-python` and `tree-sitter-go` to latest 0.25-compatible versions.
- Updated 7 direct Rust dependencies to latest major versions.
- Updated 12 WebUI dependencies to latest versions.
- Added `daat-locus-md` submodule as the markdown rendering backend.
