---
name: windows-gui-use
description: Complete Windows GUI tasks with ComputerUse across windows, controls, and handoffs.
---

Inspect the acquired window, choose the next action from its current contents,
then check the returned observation for the intended result before continuing.

For content outside the viewport, scroll or adjust the window, then inspect again.
Use magnification for visible details. After an adjustment, click the intended
editable surface again before entering text.

When a blocking dialog appears, discover and open it as a separate target, resolve
it, then observe the parent again. Choose actions from the latest supported_actions;
use a visible button when the selected control does not support the needed key.

After an uncertain launch or input, inspect actual windows and their current state
before deciding the next action. For handoff_pending, inspect the handoff status
and use release_window to finish returning the window when needed.
