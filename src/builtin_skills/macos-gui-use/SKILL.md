---
name: macos-gui-use
description: Complete macOS GUI tasks with ComputerUse across controls and separate dialog windows.
---

Inspect the acquired window and choose a supported control for the next step.
Select its editable receiver before entering text, then check the actual value.

When an app opens a dialog or child window, discover its windows again and open
the returned child as a separate target. Resolve a blocking dialog there, then
observe the parent before resuming its task.

Refresh the observation after geometry changes. After an uncertain launch or
input, inspect actual windows and their current state before deciding the next
action.
