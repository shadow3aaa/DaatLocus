---
name: android-gui-use
description: Complete Android GUI tasks with PhoneUse in the Actor's virtual display.
---

After launching an app, inspect the actual window before choosing the next step.
If the launch is unconfirmed, discover the resulting windows and inspect the
appropriate target before deciding how to continue.

For text entry, select the editable control, set the intended complete value,
then check the result before submitting or navigating onward.

After an uncertain input, observe the current window and check whether the
intended change happened before deciding the next action.
